

# Frontend - Centro Emmanuel

Frontend del Sistema de Gestión del Centro Emmanuel.

## Descripción

Este proyecto contiene la interfaz de usuario.

## Tecnologías utilizadas

 - React
 - Vite
 - JavaScript
 - HTML5
 - CSS3
 - Axios para la comunicación con el backend
 - React Router para la navegación entre vistas

## Estructura

```
frontend/
│
├── public/
├── src/
│       ├── asset/
│       ├── components/   
│       ├── pages/      
│       ├── services/      
│       ├── routes/      
│       ├── App.jsx      
│       ├── main.jsx     
│
├── .gitignore
├── eslint.config.js
├── index.html
├── package.json
├── package-lock.jason
└── vite.config.js
```

## Funcionalidades

El frontend realiza solicitudes HTTP para consultar, registrar, modificar y eliminar información.

## Requisitos

 - Node.js
 - npm
 - Git


## Ejecutar el proyecto

```bash
npm run dev
```
